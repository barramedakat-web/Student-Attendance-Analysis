# Student Attendance and Academic Performance
This project uses 50 simulated / fictional records for learning and demonstration only.
Files: `student_attendance.csv`, `analysis.R`, `app.R`, project documentation, presentation script, and publishing guide.
Quick start: upload the CSV and both R files to one Posit Cloud project folder, install `shiny`, `ggplot2`, `dplyr`, and `readr`, run `analysis.R`, then click Run App in `app.R`.
